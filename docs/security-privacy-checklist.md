# Lista de chequeo de seguridad y privacidad — Plataforma GNS (backend)

> Documento para **coordinación académica**: es la revisión de seguridad y privacidad del backend
> (BE-94). Cada punto tiene un criterio verificable, su evidencia y un estado. La evidencia es una
> prueba automática (ruta del archivo y nombre de la prueba) o una inspección (archivo o comando
> revisado y su resultado), de modo que cualquiera puede repetirla.

## Alcance y datos de la revisión

| Dato                  | Valor                                                                                                          |
| --------------------- | -------------------------------------------------------------------------------------------------------------- |
| Alcance               | API (`apps/api`), base de datos, almacenamiento de archivos y su configuración. **Sin pantallas ni despliegue.** |
| Rama revisada         | `feat/51-be-9-e2e-seguridad` (Work Item BE-9, hija #51 de la épica BE-9), sobre `5cd1470`                      |
| Elaborada             | 2026-11-14                                                                                                     |
| Commit aprobado       | _Se completa al aprobar (ver «Aprobación de coordinación»)_                                                    |
| Pruebas que respaldan | unitarias, de integración y de base de datos del backend, y las de punta a punta de `apps/api/test/e2e/`       |

**Estados:** `cumple` (ya estaba bien y hay evidencia), `corregido` (se encontró un problema y se
arregló en esta revisión), `pendiente de despliegue` (depende del entorno de producción, que está
fuera de esta fase), `riesgo aceptado` (hay una limitación conocida con su motivo; coordinación la
confirma al aprobar este documento) y `pendiente` (hallazgo que exige una decisión o un cambio no
previsto; ninguno hoy).

Las rutas de pruebas son relativas a `apps/api/`. «Matriz de acceso» es
`test/integration/access-control.int-spec.ts`; «e2e» son las pruebas de `test/e2e/`.
